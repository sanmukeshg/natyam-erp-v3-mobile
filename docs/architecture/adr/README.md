# Architecture Decision Records — NATYAM ERP

An ADR captures a significant architectural decision, the context that prompted it, the
alternatives considered, and its consequences — so a future reader (including a future
version of whoever is working on this codebase) knows *why* something is built the way it
is, not just *what* it does. Once accepted, an ADR is not edited to match later changes;
a decision that is later reversed or replaced gets a new ADR that supersedes it.

This index did not exist before ADR-014; it is created alongside that record so subsequent
ADRs have somewhere to be listed.

## Numbering note

This index starts at ADR-014 because that is the identifier this record was created under.
No ADR-001 through ADR-013 exist in this repository's `docs/architecture/adr/` folder — if
earlier architectural decisions for this project are recorded elsewhere, they have not been
consolidated here yet. Do not assume ADR-001–013 are available for reference from this index.
